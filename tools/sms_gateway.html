Use any Android phone (your dual-SIM device, spare phone, or secondary phone) as a free 24/7 SMS Gateway:

  1. Install the free open-source app SMS Forwarder (Available on F-Droid / Google Play / GitHub).
  2. In the app, tap Senders → Add Rule → Set Target to Webhook (HTTP POST).
  3. Paste your Vercel Webhook URL:
    https://telemetry-news-weather.vercel.app/api/sms
  4. Enable "Auto-reply using webhook response" in the app settings.
  5. That's it! Whenever you send an SMS to that number, it forwards to Halo and instantly texts you back. Receiving SMS is 100% free on Safaricom / Airtel!

Run a native autonomous background listener inside Termux on any Android phone with zero third-party subscriptions:

  1. Install Termux and Termux:API from F-Droid.
  2. Run this single command in Termux:
    pkg install python termux-api && pip install httpx && curl -sSL https://raw.githubusercontent.com/PANDEMICDRAGON/MYBOT/master/scripts/termux_sms_halo.py -o termux_sms_halo.py && python termux_sms_halo.py
  3. It automatically listens for SMS from you with keyword halo, calls your 24/7 Vercel cloud node, and texts you back directly using the SIM card!

Connect directly to Safaricom & Airtel Kenya cellular infrastructure using Africa's Talking (based in Nairobi):

  1. Create a free account at africastalking.com.
  2. Go to SMS → SMS Callback URLs → Incoming Messages.
  3. Set the Callback URL to:
    https://telemetry-news-weather.vercel.app/api/sms
  4. Add AT_API_KEY and AT_USERNAME to your Vercel Environment Variables.

Use a global virtual phone number with Twilio trial credits:

  1. In Twilio Console → Phone Numbers → Configure.
  2. Under A MESSAGE COMES IN, select Webhook (HTTP POST).
  3. Paste:
