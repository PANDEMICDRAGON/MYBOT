Connect directly to Safaricom & Airtel shortcodes via Africa's Talking (Nairobi, Kenya):

  1. Log into your dashboard at africastalking.com.
  2. Go to SMS → Shortcodes → Inbound → Callback URL (or Sandbox: Shortcodes → Callback URLs).
  3. Paste your live Vercel SMS endpoint:
    https://telemetry-news-weather.vercel.app/api/sms
  4. If using a shared shortcode (e.g. 20880 or sandbox 99999), set your keyword to HALO or CORTANA. Any SMS starting with HALO <text> is automatically stripped and routed to Halo's reasoning core!
  5. Add your credentials to your Vercel Environment Variables:
    AT_API_KEY=your_key
    AT_USERNAME=your_username
    AT_SHORTCODE=20880
    AT_KEYWORD=HALO
  6. Test via AT Simulator: Open Africa's Talking Sandbox → Launch Simulator → Select "Shortcodes" → Enter your shortcode → Text HALO status. You'll receive instant response!

Bring Halo onto WhatsApp using Meta Cloud WhatsApp API or Africa's Talking:

  1. Option A: Meta WhatsApp Cloud API (Official & Free 1,000 chats/mo):
    • Go to developers.facebook.com → Create App → WhatsApp.
    • In WhatsApp → Configuration → Webhook:
      Callback URL: https://telemetry-news-weather.vercel.app/api/whatsapp
      Verify Token: cortana_whatsapp_2026
    • Subscribe to messages webhook field.
    • Add WHATSAPP_ACCESS_TOKEN and WHATSAPP_PHONE_NUMBER_ID to Vercel.
  2. Option B: Africa's Talking WhatsApp Channel:
    • Go to Africa's Talking → WhatsApp Channels → Webhooks.
    • Set Webhook URL to: https://telemetry-news-weather.vercel.app/api/whatsapp.
    • Set AT_WHATSAPP_NUMBER in your environment variables.
  3. Option C: Twilio WhatsApp Sandbox:
    • In Twilio Console → Messaging → WhatsApp Sandbox → Set incoming URL to: https://telemetry-news-weather.vercel.app/api/whatsapp.

Use any Android phone (spare phone or secondary SIM) as a 100% free cellular gateway:

  1. Install the free open-source app SMS Forwarder (F-Droid / Google Play).
  2. Tap Senders → Add Rule → Set Target to Webhook (HTTP POST).
  3. Paste your Vercel Webhook URL:
    https://telemetry-news-weather.vercel.app/api/sms
  4. Enable "Auto-reply using webhook response" in settings.

Run a native background GSM listener inside Termux on any Android phone:

  1. Install Termux and Termux:API from F-Droid.
  2. Run this single command:
    pkg install python termux-api && pip install httpx && curl -sSL https://raw.githubusercontent.com/PANDEMICDRAGON/MYBOT/master/scripts/termux_sms_halo.py -o termux_sms_halo.py && python termux_sms_halo.py
